Términos de uso

Las reglas para usar este sitio y su API.

El servicio

SmartTicket clasifica tickets de soporte con un modelo de aprendizaje automático. Las predicciones pueden equivocarse; por eso los tickets dudosos pasan a revisión humana. No tomes decisiones críticas basándote solo en una predicción.

Uso aceptable

No envíes contenido ilegal, datos de terceros sin su permiso ni tráfico automatizado que busque saturar el servicio. La API tiene límites de uso por dirección IP; si los superas, las peticiones se rechazan durante unos minutos.

Tu contenido

Los tickets que envías se guardan para que el equipo pueda revisarlos. Al tratarse de una demostración, el contenido puede borrarse en cualquier momento y sin aviso.

Código y datos

El código de SmartTicket es abierto y se distribuye con licencia MIT. El modelo se entrenó con un conjunto de datos público con licencia CC BY-NC 4.0, así que el uso comercial del modelo entrenado puede estar restringido.

Sin garantías

El servicio se ofrece tal cual, sin garantía de disponibilidad ni de exactitud. Podemos cambiar estos términos; la fecha de abajo indica la versión vigente.
